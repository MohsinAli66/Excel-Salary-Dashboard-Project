# 📊 Excel Salary Dashboard

An interactive **Excel Salary Dashboard** created to explore and analyze data analyst job salaries across different roles, countries, job types, and platforms.

## 🔍 Dashboard Features

- Select different **Job Titles**
- Filter by **Country/Region**
- Analyze different **Job Types**
- View **Median Salary**
- See the number of available **Job Listings**
- Identify the platforms where jobs are posted

## 🛠️ Tools Used

- Microsoft Excel
- Data Cleaning
- Excel Formulas
- Data Validation
- Interactive Dashboard Design

## 🎯 Purpose

This project was created to practice **data analysis, Excel dashboard development, and data visualization** using a real-world job salary dataset.
